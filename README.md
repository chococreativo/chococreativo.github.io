# Edgar Altamar M. · Choco Creativo

Portafolio de Edgar Altamar M., diseñador gráfico. Publicado en https://chococreativo.github.io

## Cómo editar el contenido

1. Entra a https://app.pagescms.org e inicia sesión con GitHub.
2. Abre el repositorio `chococreativo.github.io`.
3. En **Trabajos** agregas, editas o borras proyectos (título, categoría, imagen, descripción y enlace).
4. En **Información general** cambias tu foto, textos, servicios, herramientas, correo y Behance.
5. Guarda. El sitio se actualiza solo en uno o dos minutos.

## Archivos

- `index.html`, `assets/css/style.css`, `assets/js/main.js`: el sitio.
- `content/sitio.json`, `content/proyectos.json`: el contenido que edita el panel.
- `.pages.yml`: la configuración del panel.
- `manifest.webmanifest`, `sw.js`, `assets/icons/`: lo que permite instalarlo como app.
